#### 底层高性能基础设施

**2026.03 - 2026.07**

包含 2 个独立子项目：Nexus_Gateway、MiniSQL 轻量数据库 Demo

**子项目1 | Nexus_Gateway 自研 HTTP 代理网关（个人独立项目）**

- 基于 C 语言实现高性能 HTTP 代理网关，支持四层 TCP、七层 HTTP 转发与静态文件服务、上游健康检查
- 采用 Epoll IO 多路复用 + Master Worker 多进程事件驱动架构，使用 sendfile/splice 零拷贝系统调用做 IO 优化
- 压测数据：1KB 小包 QPS 达到 650，50MB 静态文件吞吐 2.81GB/s
- 完整实现：HTTP/1.1 状态机解析、代理头改写、令牌桶限流、IP 黑名单、上游健康检查、配置热更、Nginx 格式访问日志、平滑重启

- 参考 MySQL 架构，从零构建轻量级关系型数据库 Demo，实现 SQL 解析、查询优化与并发服务等基础服务
- C++ 实现 SQL 词法/语法解析器，基于火山模型搭建查询执行引擎，支持常用 DDL/DML 语句
- B+Tree 磁盘多级索引，支持主键、普通索引查询优化；实现 WAL 预写日志，完成基础事务并发控制
