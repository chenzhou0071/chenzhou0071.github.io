这里是「舟上码途」的第一篇文章。

## 为什么开这个博客

学过的技术很多，真正沉淀下来的很少。很多项目做完就放进了仓库角落，当时踩过的坑、想通的道理，几个月后回头再看，已经想不起细节。

这大概是因为学习大多是单向的：看书、看文档、跟着教程跑通 demo，输入很多，输出很少。输入的东西没有经过整理和表达，很快就会模糊成一团。

所以开了这个博客：把做过的事、踩过的坑、想明白的问题都写下来。

写作是很好的检验方式——如果一个东西讲不清楚，往往是自己也没真懂。把知识组织成文字的过程，就是在逼自己把「好像懂了」变成「真的懂了」。写下来的东西，也更容易在需要的时候被想起来。

如果能顺便帮到看到这里的你，少走几步弯路，那就更好了。

## 写什么

我是一名计算机专业的学生，主攻后端，擅长用 C / C++ / Go / Java / Python 等语言编写项目，关注网络编程、网关、数据库这些方向，也在折腾大模型应用和游戏开发。这个博客大致围绕三个主题：

- **项目复盘**：自研项目的完整回顾——怎么设计、怎么选型、踩了什么坑
- **面试经验**：真实面试的记录与整理，八股也好、算法也罢，都是学习素材
- **开发日志**：编码日常，学到的新东西，犯过的错误

## 关于这个站点

博客用 Hugo + PaperMod 构建，源码在 [chenzhou0071.github.io 仓库](https://github.com/chenzhou0071/chenzhou0071.github.io)，写好的文章 push 上去，GitHub Actions 会自动构建部署。

文章底部有 giscus 评论，欢迎留言交流。

## 写在最后

「舟上码途」——在代码的航道上行舟，记录沿途的风景与风浪。

第一篇很短，但至少开了一个头。这个博客会一直写下去：项目做完了就写复盘，面试结束了就写记录，学到新东西了就随手记一笔。不求每篇都是干货，只求真实、持续。

如果你觉得哪篇有用，或者哪里讲得不对，欢迎在评论区聊聊，也欢迎提出想看的主题。

后面的路还长，我们航道上见。
